🔎 Materi Searching

1. Linear Search

Pengertian: mencari nilai dengan memeriksa data satu per satu dari awal sampai ketemu.

Cara kerja: bandingkan target dengan tiap elemen secara berurutan.

Contoh sehari-hari: mencari nama di daftar absen yang belum urut.

  1. Mulai dari indeks 0.
  2. Bandingkan elemen dengan target.
  3. Jika sama, berhenti: ditemukan.
  4. Jika tidak, lanjut ke indeks berikutnya.
  5. Jika data habis, target tidak ada.

👍 Mudah, data tak perlu terurut. 👎 Lambat untuk data besar.

2. Binary Search

Pengertian: mencari pada data terurut dengan membagi dua daerah pencarian.

Cara kerja: cek nilai tengah; buang separuh data yang tidak mungkin berisi target.

Contoh sehari-hari: mencari kata di kamus dengan membuka halaman tengah.

  1. Tentukan batas kiri dan kanan.
  2. Hitung indeks tengah.
  3. Jika tengah = target, selesai.
  4. Jika tengah < target, cari di kanan; jika lebih besar, cari di kiri.
  5. Ulangi sampai ketemu atau batas habis.

👍 Sangat cepat. 👎 Data wajib terurut.

📊 Materi Sorting

1. Bubble Sort

Definisi: mengurutkan dengan menukar dua elemen bersebelahan yang salah urutan, berulang kali.

Cara kerja: nilai terbesar "menggelembung" ke ujung kanan di setiap putaran.

Penggunaan: belajar konsep, data sangat kecil.

ulangi n-1 kali
  untuk j = 0 .. n-2-i
    jika a[j] > a[j+1]
      tukar a[j], a[j+1]

2. Insertion Sort

Definisi: menyisipkan tiap elemen ke posisi yang tepat pada bagian kiri yang sudah terurut.

Cara kerja: seperti menyusun kartu remi di tangan.

Penggunaan: data kecil atau hampir terurut.

untuk i = 1 .. n-1
  j = i
  selama j > 0 dan a[j-1] > a[j]
    tukar a[j-1], a[j]
    j = j - 1

3. Selection Sort

Definisi: memilih nilai terkecil dari sisa data lalu menaruhnya di posisi paling depan.

Cara kerja: cari minimum, tukar, lanjutkan ke posisi berikutnya.

Penggunaan: bila jumlah pertukaran harus sedikit.

untuk i = 0 .. n-2
  min = i
  untuk j = i+1 .. n-1
    jika a[j] < a[min]: min = j
  tukar a[i], a[min]

📚 Materi Struktur Data

Stack — LIFO (Last In First Out)

Data terakhir yang masuk adalah yang pertama keluar. Masuk dan keluar lewat sisi atas. Contoh: tumpukan piring, tombol Undo, riwayat Back di browser.

Queue — FIFO (First In First Out)

Data pertama yang masuk dilayani lebih dulu. Masuk dari belakang, keluar dari depan. Contoh: antrean kasir, antrean cetak printer, antrean tiket online.

📌 Rangkuman

🔎 Searching

Linear: periksa satu per satu, data bebas. Binary: bagi dua, data harus terurut, jauh lebih sedikit langkah.

📊 Sorting

Bubble menukar tetangga, Insertion menyisipkan, Selection memilih terkecil. Ketiganya O(n²).

📚 Stack

LIFO · PUSH & POP di atas.

🚶 Queue

FIFO · ENQUEUE di belakang, DEQUEUE di depan.
